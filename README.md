# Corporate Omissions

Replication code for:

> **Corporate Omissions: Strategic Silence and the Price of Non-Disclosure**\
> Giulia Crippa (Princeton University), Florian Berg (MIT Sloan), Roberto Rigobon (MIT Sloan)\
> [SSRN Working Paper](https://papers.ssrn.com/sol3/papers.cfm?abstract_id=5503418)

The project models corporate carbon disclosure as a strategic decision in which
non-disclosure depends on latent emissions through a single selection severity index,
recovers Scope 1 emissions for the firms that never disclose via exponential tilting,
and prices the disclosure decision in the cross-section of returns.

---

## This repository contains no data

The emissions, accounting and returns data used in the paper are licensed from
**S&P Trucost**, **Compustat** and **CRSP** and cannot be redistributed. Nothing under
`data/` is included here, and the pipeline will not run until you supply the inputs
yourself from your own institutional subscription (most commonly through WRDS).

Create the directory tree and place the files at these exact paths:

```
data/
├── raw/          # you supply these
└── processed/    # generated by the pipeline
```

| Path | Source | Access | Contents |
|------|--------|--------|----------|
| `data/raw/trucost.csv` | S&P Trucost (via WRDS) | Licensed | Firm-year Scope 1 emissions, disclosed and vendor-estimated |
| `data/raw/fundamentals.csv` | Compustat (via WRDS) | Licensed | Total assets, revenue, gross PP&E, GICS sector and industry codes |
| `data/raw/gdp.csv` | FRED | Free | Real GDP, used as an instrument in the baseline specification |
| `data/raw/fred_energy.csv` | FRED | Free | WTI crude spot price and petroleum PPI, used in the shift-share instrument |
| `Returns/F-F_Research_Data_5_Factors_2x3.csv` | Ken French Data Library | Free | Fama-French five factors, monthly |
| `Returns/F-F_Momentum_Factor.csv` | Ken French Data Library | Free | Momentum factor, monthly |
| `Returns/HHI.csv` | Derived from Compustat | Licensed | Industry concentration (Herfindahl index) |

Monthly returns come from **CRSP** and are pulled directly in
`notebooks/07_build_returns_data.ipynb`; you will need WRDS credentials for that step
rather than a file on disk.

Everything under `data/processed/` and `data/outputs/` is generated — do not create
these by hand.

## Environment

```bash
conda env create -f environment.yml
conda activate corporate-omissions
```

To reproduce the exact environment used for the results in the paper:

```bash
conda env create -f environment.lock.yml
conda activate corporate-omissions
```

The `Returns/` analysis is in R and is not covered by the conda environment. It requires
`data.table`, `fixest`, `zoo`, `sandwich` and `lmtest`.

## Pipeline

Run the notebooks in order. Later stages depend on the `.parquet` files written by
earlier ones.

| Notebook | Description |
|----------|-------------|
| `00_pipeline_overview` | Environment validation and path setup |
| `01_load_raw` | Load the raw vendor extracts |
| `02_merge_panel` | Merge sources into a unified firm-year panel |
| `03_preprocess_data` | Cleaning, winsorization, outlier removal, exchange filter |
| `04_imputation_300mc` | Main imputation run: outcome model, propensity, Monte Carlo tilting |
| `04_imputation_500mc` | Same with 500 draws, as a convergence check |
| `04a_imputation_ivs` | Instrument sensitivity (GDP vs. WTI vs. shift-share) |
| `04b_imputation_gamma` | Selection severity: by sector, by ownership, and the audience-by-brownness test |
| `04c_imputation_val` | Imputation validation (rank correlation, prediction error by quantile) |
| `05_aggregate_implications` | Aggregate emissions and corporate carbon damages |
| `06_transitioning_companies` | Accuracy for firms transitioning from estimated to disclosed |
| `06a_oos_transition_validation` | Out-of-sample validation on transition firms |
| `07_build_IO` | Build the institutional-ownership panel from 13F holdings |
| `07_build_returns_data` | Build the firm-month returns panel (CRSP/Compustat via WRDS) |

Then the R scripts in `Returns/`, which read the panel produced above. Source
`00_setup.R` first; the rest are standalone.

| Script | Description |
|--------|-------------|
| `00_setup.R` | Shared data loader, variable construction, helper functions |
| `01_diagnostic.R` | Sample composition diagnostics |
| `02_pricing_never_disclosing.R` | Carbon premium among never-disclosing firms |
| `03_event_study.R` | SEC March 2022 climate-disclosure proposal event study |
| `03a_event_study_placebos.R` | Placebo-date distribution for the event study |
| `04_bk_intensity.R` | Bolton-Kacperczyk replication on emissions intensity |
| `05_mechanisms.R` | Disclosure premium, ESG-salience period split, disclosure surprise |
| `06_did_analysis.R` | Within-firm transition difference-in-differences |
| `07_pricing_portfolios.R` | Portfolio sorts and Fama-MacBeth regressions |
| `08_premium_audience.R` | Transparency premium interacted with institutional ownership |

## Specifications

The pipeline notebooks are parameterized by a `SPEC` dictionary in the first code cell.
Edit it and re-run to reproduce the baseline or any robustness variant. Pre-configured
options are included, commented out, in the notebooks:

| Spec | Instrument | MC draws | Notes |
|------|-----------|----------|-------|
| `baseline` | log GDP | 300 | GICS industry controls, GAM propensity enabled |
| `wti` | log WTI crude | 300 | GICS sector controls |
| `500mc` | GDP | 500 | Convergence check, LM propensity only |
| `tilt_test` | Shift-share (WTI × predetermined PP&E intensity) | 300 | Adds an emissions × post-2021 interaction and the year-by-year selection severity; this is the specification behind the figures in the paper |

Outputs are tagged with the spec name (for example `df_lm_avg_baseline_wti_gind.parquet`,
`gamma_by_io_fullwindow_tilt_test.pdf`) so specifications never overwrite one another.

Reusable logic lives in `src/corporate_omissions/`; the notebooks are thin orchestration
and presentation layers.

## Known limitations

- Several scripts in `Returns/` and two notebooks contain absolute paths pointing at the
  original author's machine. Adjust these to your own working directory before running.
